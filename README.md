<h1 align="center">彩り Irodori</h1>
<p align="center"><i>Image editing with layers, masks and adjustments. Part of 工房 Kōbō.</i></p>

Irodori is CuteClaudia's image editor, for **Windows** and **Linux**, and in the browser on
[claudiagilbert.com](https://www.claudiagilbert.com). Download the latest version from
**[Releases](https://github.com/cuteclaudia/irodori-releases/releases/latest)**.

| Platform | Download | How to install |
|---|---|---|
| Windows 10 / 11 (64-bit) | `irodori-<version>-windows-x64-setup.exe` | Run it. If Windows shows "Windows protected your PC", choose **More info → Run anyway** (or right-click the file → Properties → **Unblock**). |
| Windows, no install | `irodori-<version>-windows-x64-portable.zip` | Unzip and run `irodori.exe`. |
| Linux (any distro) | `irodori-<version>-linux-x86_64.AppImage` | Make it executable, then run it. |
| Ubuntu, Debian, Mint | `irodori-<version>-linux-x86_64.deb` | Open it with your software centre, or `sudo apt install ./irodori-*.deb`. |
| Fedora, openSUSE | `irodori-<version>-linux-x86_64.rpm` | `sudo dnf install ./irodori-*.rpm` |

Each release lists `SHA256SUMS.txt` to check your download. Every release passes a security
check first: known vulnerabilities, where its code comes from, everything it can connect to, and
a virus scan of the files. Installed copies offer new versions when they're published here.

Irodori is based on [PhotoCraft](https://github.com/storytold/photocraft) by the ArtCraft Team and
the PhotoCraft contributors, and is licensed MIT OR Apache-2.0.
